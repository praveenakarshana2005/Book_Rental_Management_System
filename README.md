# 📚 Book Rental Management System

## 📖 Overview

The **Book Rental Management System** is a software application designed to manage the process of renting books efficiently.
It helps users handle book inventory, customer details, and rental transactions in an organized and user-friendly way.

---

## 🚀 Features

* 📌 Add, update, and delete books
* 👤 Manage customer details
* 🔄 Book rental and return system
* 📊 Generate reports
* 🔍 Search and filter books
* 🔐 Secure and structured system

---

## 🛠️ Technologies Used

* 💻 **Java (Java FX / Spring Boot)**
* 🗄️ **MySQL Database**
* 🔗 **JDBC / Hibernate (if used)**
* 🧰 **Maven**

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```bash
git clone https://github.com/praveenakarshana2005/Book_Rental_Management_System.git
```

### 2️⃣ Navigate to project folder

```bash
cd Book_Rental_Management_System
```

### 3️⃣ Configure Database

* Create a MySQL database
* Update `application.properties` or DB config file

### 4️⃣ Run the project

* Open in **IntelliJ / NetBeans / VS Code**
* Run the main class
